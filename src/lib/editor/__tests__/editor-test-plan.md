# 戯曲エディタ テスト計画

## 1. テキスト入力

### 1.1 空フィールドへの入力
- [ ] 空のspeaker → 文字入力
- [ ] 空のspeech → 文字入力
- [ ] 空のtogaki text → 文字入力
- [ ] 空のsceneHeading text → 文字入力
- [ ] 空のsetting text → 文字入力
- [ ] 空のtitle → 文字入力
- [ ] 空のauthor → 文字入力

### 1.2 既存テキストへの入力
- [ ] テキスト先頭に挿入
- [ ] テキスト中間に挿入
- [ ] テキスト末尾に挿入
- [ ] 1文字だけのフィールドに追加

### 1.3 日本語IME入力
- [ ] ひらがな入力（変換なし確定）
- [ ] 漢字変換して確定
- [ ] 変換中にESCでキャンセル
- [ ] 連続で複数の日本語を入力
- [ ] IME入力後すぐに英数字入力

### 1.4 特殊入力
- [ ] 英数字入力
- [ ] 記号入力（。、！？…）
- [ ] 絵文字入力
- [ ] 長文の連続入力（1列溢れ）

## 2. カーソル移動

### 2.1 矢印キー
- [ ] 縦書き: ↓で文字送り（下へ）
- [ ] 縦書き: ↑で文字戻り（上へ）
- [ ] 縦書き: ←で次ブロック
- [ ] 縦書き: →で前ブロック
- [ ] 横書き: →で文字送り
- [ ] 横書き: ←で文字戻り
- [ ] 横書き: ↓で次ブロック
- [ ] 横書き: ↑で前ブロック
- [ ] テキスト先頭で戻り（何も起きない）
- [ ] テキスト末尾で送り（何も起きない）

### 2.2 クリック
- [ ] セリフのspeechエリアをクリック
- [ ] セリフのspeakerエリアをクリック
- [ ] ト書きのテキストエリアをクリック
- [ ] タイトルをクリック
- [ ] 作者名をクリック
- [ ] 空のフィールドをクリック
- [ ] ブロック間の空白をクリック
- [ ] 登場人物をクリック（編集不可）

## 3. ブロック操作

### 3.1 Enter キー
- [ ] speaker上でEnter → speechに移動
- [ ] speech上でEnter → 新しいserifを作成、speakerにカーソル
- [ ] title上でEnter → authorに移動
- [ ] togaki上でEnter → 新しいserifを作成
- [ ] sceneHeading上でEnter → 新しいserifを作成
- [ ] setting上でEnter → 新しいserifを作成

### 3.2 Backspace キー
- [ ] テキスト中の文字を削除
- [ ] テキスト先頭でBackspace（何も起きない or 前ブロックへ）
- [ ] 空のspeech → speakerに移動
- [ ] 空のspeaker + 空のspeech → ブロック削除
- [ ] 最後の1ブロックでは削除しない
- [ ] タイトルブロックは削除しない

### 3.3 ツールバーからの挿入
- [ ] セリフ挿入
- [ ] ト書き挿入
- [ ] 場面挿入
- [ ] 舞台設定挿入
- [ ] 終幕挿入

### 3.4 ブロック移動
- [ ] Ctrl+Shift+↑ でブロック上移動
- [ ] Ctrl+Shift+↓ でブロック下移動
- [ ] 先頭ブロックを上移動（何も起きない）
- [ ] 末尾ブロックを下移動（何も起きない）
- [ ] パネルのドラッグ&ドロップ
- [ ] Canvas上のドラッグ&ドロップ（横書き）
- [ ] Canvas上のドラッグ&ドロップ（台本）

### 3.5 ブロック種別変更
- [ ] セリフ → ト書き（speechテキストを保持）
- [ ] ト書き → セリフ（textをspeechに移行）
- [ ] セリフ → 場面
- [ ] 場面 → セリフ

### 3.6 ブロック削除
- [ ] パネルから削除
- [ ] 空ブロックBackspaceで削除
- [ ] 削除後のカーソル位置が正しい

## 4. 選択・コピペ

### 4.1 マウスドラッグ選択
- [ ] テキスト上でドラッグして範囲選択
- [ ] 選択中にハイライト表示

- [ ] Cmd+V でペースト

### 4.4 Backspace/Delete
