# Gikyoku Joen Constitution

## Core Principles

### I. ユーザー中心設計
すべての機能は、戯曲の執筆者・読者・上演希望者の3つのペルソナを軸に設計する。機能追加時は「どのペルソナのどの課題を解決するか」を明示しなければならない。

### II. モダンWeb標準
レスポンシブデザイン、アクセシビリティ（WCAG 2.1 AA準拠）、SEO最適化を標準とする。はりこのトラの穴との差別化として、現代的なUI/UXを提供する。

### III. テスト重視
主要機能にはテストを書く。特に上演許可申請フロー、認証・認可、決済関連はテスト必須とする。

### IV. セキュリティ・プライバシー
ユーザーの個人情報、戯曲の著作権を保護する。OWASP Top 10に準拠したセキュリティ対策を実施する。上演許可の権利管理は厳格に行う。

### V. シンプルさ
YAGNI原則を守る。必要最小限の機能から始め、ユーザーフィードバックに基づいて拡張する。過度な抽象化を避ける。

## 技術方針

- 日本語を主言語とするサービスであり、i18nは初期段階では不要
- モバイルファーストのレスポンシブデザイン
- 戯曲テキストの全文検索機能を将来的に実装可能な設計

## Governance

Constitution の変更は、変更内容の文書化と影響範囲の評価を行った上で実施する。
