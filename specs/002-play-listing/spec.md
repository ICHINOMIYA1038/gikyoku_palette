# Feature Specification: 戯曲一覧・検索

**Feature Branch**: `002-play-listing`
**Created**: 2026-03-17
**Status**: Draft

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 戯曲一覧の閲覧 (Priority: P1)

ユーザー（未ログインでも可）がサイトにアクセスし、公開されている戯曲の一覧をカード形式で閲覧できる。各カードにはタイトル、執筆者名、あらすじ抜粋、上演時間、出演人数、ジャンルが表示される。

**Why this priority**: サイトのメインコンテンツへの入口。ユーザーが最初に触れる体験。

**Independent Test**: トップページにアクセスし、戯曲カードが一覧表示されることを確認。

**Acceptance Scenarios**:

1. **Given** 公開中の戯曲が存在する, **When** ユーザーが一覧ページにアクセスする, **Then** 戯曲がカード形式で一覧表示される
2. **Given** 戯曲が20件以上存在する, **When** ユーザーが一覧ページにアクセスする, **Then** ページネーションまたは無限スクロールで追加読み込みできる
3. **Given** 未ログインのユーザー, **When** 一覧ページにアクセスする, **Then** ログインなしで戯曲一覧を閲覧できる

---

### User Story 2 - キーワード検索 (Priority: P1)

ユーザーがキーワードを入力して、タイトル・執筆者名・あらすじから戯曲を検索できる。

**Why this priority**: 目的の作品を見つけるための基本機能。

**Independent Test**: 検索バーにキーワードを入力し、該当する戯曲が結果に表示されることを確認。

**Acceptance Scenarios**:

1. **Given** 検索バーが表示されている, **When** 「家族」と入力して検索する, **Then** タイトル・執筆者名・あらすじに「家族」を含む戯曲が表示される
2. **Given** 検索キーワードに該当する戯曲がない, **When** 検索を実行する, **Then** 「該当する作品が見つかりませんでした」と表示される

---

### User Story 3 - 条件フィルタリング (Priority: P2)

ユーザーが上演時間、出演人数、ジャンルなどの条件で戯曲を絞り込める。演劇部やサークルが自分たちの条件に合う作品を効率的に探せる。

**Why this priority**: 特に高校演劇部など、制約条件のあるユーザーにとって重要。キーワード検索だけでは見つけにくい。

**Independent Test**: フィルタ条件を設定し、条件に合致する戯曲のみが表示されることを確認。

**Acceptance Scenarios**:

1. **Given** 一覧ページが表示されている, **When** 上演時間「60分以内」でフィルタする, **Then** 上演時間が60分以内の戯曲のみ表示される
2. **Given** 一覧ページが表示されている, **When** 出演人数「5人以下」でフィルタする, **Then** 出演人数が5人以下の戯曲のみ表示される
3. **Given** 一覧ページが表示されている, **When** ジャンル「コメディ」でフィルタする, **Then** コメディの戯曲のみ表示される
4. **Given** 一覧ページが表示されている, **When** 複数のフィルタを組み合わせる, **Then** すべての条件を満たす戯曲のみ表示される

---

### User Story 4 - 並び替え (Priority: P2)

ユーザーが一覧の並び順を変更できる。新着順、人気順などで戯曲を探せる。

**Why this priority**: コンテンツの発見性を高める機能だが、最低限の新着順があればMVPとしては成立する。

**Independent Test**: 並び替えオプションを選択し、順番が変わることを確認。

**Acceptance Scenarios**:

1. **Given** 一覧ページが表示されている, **When** 「新着順」を選択する, **Then** 公開日が新しい順に表示される
2. **Given** 一覧ページが表示されている, **When** 「閲覧数順」を選択する, **Then** 閲覧数が多い順に表示される

---

### Edge Cases

- 戯曲が0件の場合 → 「まだ作品が登録されていません」と表示
- フィルタ条件の組み合わせで0件になる場合 → 「条件に合う作品が見つかりませんでした。条件を変更してお試しください」と表示
- 検索キーワードが極端に長い場合 → 入力文字数制限（100文字）を設ける
- 大量の戯曲（1000件以上）がある場合 → ページネーションで1ページ20件ずつ表示

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST 公開中の戯曲をカード形式で一覧表示する
- **FR-002**: System MUST 各カードにタイトル、執筆者名、あらすじ抜粋（100文字）、上演時間、出演人数、ジャンルを表示する
- **FR-003**: System MUST キーワードによる全文検索を提供する（タイトル、執筆者名、あらすじが対象）
- **FR-004**: System MUST 上演時間でのフィルタリングを提供する（30分以内/60分以内/90分以内/制限なし）
- **FR-005**: System MUST 出演人数でのフィルタリングを提供する（1-3人/4-6人/7-10人/11人以上）
- **FR-006**: System MUST ジャンルでのフィルタリングを提供する
- **FR-007**: System MUST 複数フィルタの組み合わせ（AND条件）に対応する
- **FR-008**: System MUST 並び替え機能を提供する（新着順、閲覧数順）
- **FR-009**: System MUST ページネーションを提供する（1ページ20件）
- **FR-010**: System MUST 未ログインユーザーにも一覧・検索を公開する
- **FR-011**: System MUST 検索結果が0件の場合に適切なメッセージを表示する

### Key Entities

- **Play（戯曲）**: タイトル、あらすじ、上演時間（分）、出演人数（合計、男、女、不問）、ジャンル、公開状態、閲覧数、公開日時、執筆者（Userへの参照）
- **Genre（ジャンル）**: ジャンル名。コメディ、シリアス、ミュージカル、時代劇、ファンタジー、SF、ホラー、その他

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 一覧ページが2秒以内に表示される
- **SC-002**: 検索結果が1秒以内に返される
- **SC-003**: ユーザーが3ステップ以内に目的の戯曲にたどり着ける（検索またはフィルタ経由）
- **SC-004**: モバイル端末でも快適に一覧を閲覧・操作できる
